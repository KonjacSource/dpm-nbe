## DPM-NBE

Experiments on implementing Dependent Pattern Matching under Normalization by Evaluation setup.

### Syntax

Example

```agda
let trans : (A : U) (a b c : A) -> Id A a b -> Id A b c -> Id A a c =
  λ A a b c refl refl . refl; 

let cong : (A B : U) (f : A -> B) (a b : A) -> Id A a b -> Id B (f a) (f b) =
  λ A B f a b refl . refl;

let H : (m n : Nat) -> Id Nat n (plus m zero) -> Id Nat m zero -> Id Nat n zero =
  λ m n refl refl . refl;

let C : (A : U) -> Id Nat (suc zero) zero -> A = 
  λ A (!); -- Absurd pattern

U
```

Note.

- ```plus```, ```suc```, ```Id``` must be fully applied.
- ```plus``` is recursing on left argument, hence ```plus m zero``` is a neutral form.
- For simplicity, we only have ```refl``` , absurd pattern ```(!)``` and variables as patterns, ```zero``` and ```suc``` are not patterns.

  The idea is to isolate DEPENDENT part from dependent pattern matching. 

### Difficulty of DPM under NbE

The problem is that a value is not stable under substitution, for example, when we checking the following pattern matching

```agda
let H : (m n : Nat) -> Id Nat n (plus m zero) -> Id Nat m zero -> ... 
  λ m n refl refl . ...  
```

For the first ```refl```, we need to unify ```n``` with ```plus m zero```, extending the evaluation environment with ```n = plus m zero```, which is a value (corresponding to a normal form). But the second ```refl``` gives ```m = zero```, which makes the ```plus m zero [zero/m]``` no more a normal form.

## Update: Nov. 26. 2026

After a talk to my classmates and further investigation,
I found that we can actually directly delay the substitution using

```hs
data Val
  = ...
  | VD ~Val

subst :: Sub -> Val -> Val
subst s (VD v) = VD (substStrictly s v) 
                  -- ^ This is in a delayed field, 
                  -- so substStrictly is not called until we force the value.
```

And compute the substitution when we need.
Benchmark shows that it is way faster than the previous solution.

E.g. for

```hs
-- psudo code
let trans400 : Id _ a1 a2 -> Id _ a2 a3 -> ... -> Id _ a1 a400 = 
  λ refl refl ... refl . refl;
```

main branch casts to 40s, while the new solution takes only 0.188s.
Agda costs around half a minute.

For ``transN`` case, based on measurement, roughly speaking, main branch and Agda grow cubically, while the new solution grows quadratically on ``N``.

See [delayed-subst](https://github.com/KonjacSource/dpm-nbe/tree/delayed-subst) for the detailed implementation.
